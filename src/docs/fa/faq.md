## استفاده از Hivesigner {#using-hivesigner}

### آیا Hivesigner رایگان است؟ {#is-it-free}

بله. Hivesigner نه از کاربران هزینه می‌گیرد و نه از برنامه‌ها. کد منبع آن با پروانه MIT باز است.

### آیا Hivesigner هیچ‌وقت کلیدهای من را می‌بیند؟ {#keys}

نه. کلیدهای شما در مرورگرِ دستگاه خودتان می‌مانند و Hivesigner همان‌جا امضا می‌کند. آن‌ها هرگز به سرورهای Hivesigner یا به برنامه‌هایی که استفاده می‌کنید فرستاده نمی‌شوند. ببینید [کلیدهای شما کجا ذخیره می‌شوند](/docs/accounts#where-keys-are-stored) و [کلیدهای خود را ایمن نگه دارید](/docs/safety).

### اگر کد عبورم را فراموش کنم چه؟ {#forgotten-passcode}

هیچ‌کس نمی‌تواند کد عبور را بازیابی کند، حتی Hivesigner. حساب را از Hivesigner حذف کنید و آن را با کلید Hive و یک کد عبور تازه دوباره بیفزایید. حساب Hive شما و برنامه‌هایی که مجاز کرده‌اید تغییری نمی‌کنند. ببینید [اگر کد عبور خود را فراموش کردید](/docs/accounts#forgotten-passcode).

### آیا می‌توانم Hivesigner را روی گوشی استفاده کنم؟ {#phone}

بله. https://hivesigner.com را در مرورگر گوشی باز کنید و حسابتان را همان‌جا بیفزایید. کلیدها تنها در همان مرورگر ذخیره می‌شوند، پس روی هر دستگاهی که به کار می‌برید حساب را اضافه کنید. ببینید [افزودن و مدیریت حساب‌ها](/docs/accounts).

### کدام برنامه‌ها از Hivesigner استفاده می‌کنند؟ {#which-apps}

نشانی https://hivesigner.com/apps برنامه‌هایی را فهرست می‌کند که از طریق Hivesigner تراکنش به Hive می‌فرستند، به ترتیب بیشترین استفاده. هر برنامه نام و توضیح خود را خودش منتشر می‌کند و Hivesigner آن‌ها را تأیید نمی‌کند. باز کردن یک برنامه در آنجا صفحه‌ای را نشان می‌دهد که می‌توان از آن دسترسی انتشار به برنامه داد. ببینید [مجاز کردن یک برنامه از فهرست](/docs/signing-in#directory).

### نسبت Hivesigner با Hive Keychain چیست؟ {#hive-keychain}

این دو ابزار جدا هستند. Hive Keychain افزونه مرورگر و برنامه گوشی است، اما Hivesigner یک وب‌سایت است و چیزی برای نصب ندارد. وقتی برنامه‌ای از شما می‌خواهد پیامی را امضا کنید، امضای به‌دست‌آمده از همان گونه‌ای است که Hive Keychain می‌سازد، پس برنامه هر دو را با یک کد بررسی می‌کند. توکن تأیید صفحه **امضای پیام** در Hivesigner در صفحه **تأیید پیام** همان Hivesigner بررسی می‌شود. ببینید [امضای پیام](/docs/message-signing).

## ساختن با Hivesigner {#building}

### آیا می‌توانم Hivesigner را در برنامه گوشی به کار ببرم؟ {#mobile-app}

بله. کاربر را در یک مرورگر به Hivesigner بفرستید و از نشانی بازگشتی استفاده کنید که برنامه‌تان بتواند آن را دریافت کند: پیوند https که خودتان مالک آن هستید (Android App Links یا iOS Universal Links) یا نشانی محلی مانند `http://127.0.0.1/auth`. طرح‌های اختصاصی مانند `myapp://` رد می‌شوند. ببینید [برنامه‌های گوشی و رایانه](/docs/register-app#native-apps).

### آیا به یک حساب برنامه نیاز دارم؟ {#app-account}

برای واردکردن کاربران با دسترسی انتشار و برای ارسال تراکنش از طریق API به آن نیاز دارید. ببینید [برنامه خود را ثبت کنید](/docs/register-app). [پیوندهای امضا](/docs/sign-links) و [امضای پیام](/docs/message-signing) بدون آن هم کار می‌کنند، و همچنین [ورود بدون دسترسی انتشار](/docs/login-only).

### آیا API می‌تواند انتقال وجه انجام دهد؟ {#transfers}

نه. API فقط عملیات در سطح انتشار را ارسال می‌کند، مانند رأی، دیدگاه و دنبال کردن. برای انتقال وجه و دیگر کارهایی که به کلید فعال نیاز دارند از [پیوندهای امضا](/docs/sign-links) استفاده کنید: کاربر هر کدام را با کلید خودش تأیید می‌کند.

### کدام زبان‌ها SDK دارند؟ {#languages}

SDK رسمی برای JavaScript است. برای Python کتابخانه‌هایی از سوی جامعه وجود دارد. هر زبانی می‌تواند REST API را فراخوانی کند. ببینید [SDKها](/docs/sdk) و [REST API](/docs/api).

## راهنمایی {#help}

### از کجا کمک بگیرم؟ {#get-help}

در سرور دیسکورد HiveDevs بپرسید: https://discord.gg/pNJn7wh. اشکال‌ها را به‌صورت issue در مخزن GitHub مربوط گزارش کنید: https://github.com/ecency/hivesigner-ui برای وب‌سایت، https://github.com/ecency/hivesigner-api برای API یا https://github.com/ecency/hivesigner-sdk برای SDK جاوااسکریپت. در صفحه‌ای که درخواستی را رد می‌کند، دکمه **گزارش این مشکل** مشکل را به تیم Hivesigner می‌فرستد.

### چگونه می‌توانم مشارکت کنم؟ {#contribute}

Hivesigner در همان سه مخزن بالا روی GitHub متن‌باز است. برای اشکال یا ایده یک issue باز کنید و برای اصلاح، pull request بفرستید.
