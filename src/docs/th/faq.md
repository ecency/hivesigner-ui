คำตอบสั้น ๆ สำหรับคำถามที่พบบ่อย แต่ละข้อมีลิงก์ไปยังหน้าที่อธิบายรายละเอียด

## การใช้ Hivesigner {#using-hivesigner}

### Hivesigner ใช้ฟรีไหม {#is-it-free}

ฟรี Hivesigner ไม่เก็บค่าใช้จ่ายทั้งจากผู้ใช้และจากแอป ซอร์สโค้ดเปิดเผยภายใต้สัญญาอนุญาต MIT

### Hivesigner เคยเห็นคีย์ของฉันไหม {#keys}

ไม่เคย คีย์ของคุณอยู่ในเบราว์เซอร์บนอุปกรณ์ของคุณ และ Hivesigner ลงนามที่นั่น คีย์ไม่เคยถูกส่งไปยังเซิร์ฟเวอร์ของ Hivesigner หรือไปยังแอปที่คุณใช้ ดู[คีย์ของคุณถูกเก็บไว้ที่ไหน](/docs/accounts#where-keys-are-stored)และ[เก็บคีย์ของคุณให้ปลอดภัย](/docs/safety)

### ถ้าลืมรหัสปลดล็อกต้องทำอย่างไร {#forgotten-passcode}

ไม่มีใครกู้รหัสปลดล็อกได้ แม้แต่ Hivesigner ให้ลบบัญชีออกจาก Hivesigner แล้วเพิ่มกลับเข้ามาใหม่ด้วยคีย์ Hive และรหัสปลดล็อกใหม่ บัญชี Hive ของคุณและแอปที่คุณอนุญาตไว้จะไม่เปลี่ยนแปลง ดู[หากคุณลืมรหัสปลดล็อก](/docs/accounts#forgotten-passcode)

### ใช้ Hivesigner บนมือถือได้ไหม {#phone}

ได้ เปิด https://hivesigner.com ในเบราว์เซอร์บนมือถือแล้วเพิ่มบัญชีที่นั่น คีย์จะถูกเก็บไว้เฉพาะในเบราว์เซอร์นั้น จึงต้องเพิ่มบัญชีในทุกอุปกรณ์ที่คุณใช้ ดู[การเพิ่มและจัดการบัญชี](/docs/accounts)

### แอปใดบ้างที่ใช้ Hivesigner {#which-apps}

https://hivesigner.com/apps แสดงรายชื่อแอปที่ส่งกระจายธุรกรรมไปยัง Hive ผ่าน Hivesigner เรียงตามจำนวนการใช้งานจากมากไปน้อย แต่ละแอปเผยแพร่ชื่อและคำอธิบายของตัวเอง ซึ่ง Hivesigner ไม่ได้ตรวจสอบ เมื่อเปิดแอปที่นั่นจะเห็นหน้าที่ให้สิทธิ์ posting แก่แอปได้ ดู[อนุญาตแอปจากไดเรกทอรี](/docs/signing-in#directory)

### Hivesigner เกี่ยวข้องกับ Hive Keychain อย่างไร {#hive-keychain}

เป็นคนละเครื่องมือกัน Hive Keychain เป็นส่วนขยายของเบราว์เซอร์และแอปบนมือถือ ส่วน Hivesigner เป็นเว็บไซต์ จึงไม่ต้องติดตั้งอะไร เมื่อแอปขอให้คุณลงนามข้อความ ลายเซ็นที่ได้เป็นชนิดเดียวกับที่ Hive Keychain สร้าง แอปจึงตรวจสอบทั้งสองแบบด้วยโค้ดชุดเดียวกัน โทเค็นยืนยันจากหน้า**ลงนามข้อความ**ของ Hivesigner ตรวจได้ที่หน้า**ตรวจสอบข้อความ**ของ Hivesigner ดู[การลงนามข้อความ](/docs/message-signing)

## การพัฒนาด้วย Hivesigner {#building}

### ใช้ Hivesigner ในแอปบนมือถือได้ไหม {#mobile-app}

ได้ ส่งผู้ใช้ไปยัง Hivesigner ในเบราว์เซอร์ และใช้ที่อยู่สำหรับส่งกลับที่แอปของคุณรับได้ เช่น ลิงก์ https ที่คุณเป็นเจ้าของ (Android App Links หรือ iOS Universal Links) หรือที่อยู่ลูปแบ็กอย่าง `http://127.0.0.1/auth` สคีมเฉพาะของแอปอย่าง `myapp://` จะถูกปฏิเสธ ดู[แอปบนมือถือและเดสก์ท็อป](/docs/register-app#native-apps)

### ฉันต้องมีบัญชีสำหรับแอปไหม {#app-account}

ต้องมี หากจะให้ผู้ใช้เข้าสู่ระบบพร้อมสิทธิ์ posting และหากจะส่งกระจายธุรกรรมผ่าน API ดู[ลงทะเบียนแอปของคุณ](/docs/register-app) ส่วน[ลิงก์ลงนาม](/docs/sign-links)และ[การลงนามข้อความ](/docs/message-signing)ทำงานได้โดยไม่ต้องมี เช่นเดียวกับ[การเข้าสู่ระบบโดยไม่ขอสิทธิ์ posting](/docs/login-only)

### API ส่งเงินโอนได้ไหม {#transfers}

ไม่ได้ API ส่งกระจายเฉพาะการดำเนินการระดับ posting เช่น การโหวต ความคิดเห็น และการติดตาม สำหรับการโอนและการดำเนินการอื่นที่ต้องใช้คีย์ active ให้ใช้[ลิงก์ลงนาม](/docs/sign-links) โดยผู้ใช้จะอนุมัติแต่ละรายการด้วยคีย์ของตนเอง

### ภาษาใดบ้างที่มี SDK {#languages}

SDK อย่างเป็นทางการมีสำหรับ JavaScript ส่วน Python มีไลบรารีจากชุมชน ภาษาใดก็เรียกใช้ REST API ได้ ดู[SDK](/docs/sdk)และ[REST API](/docs/api)
