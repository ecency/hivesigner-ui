Hivesigner ลงนามด้วยคีย์ของบัญชี Hive ที่คุณเพิ่มเข้ามา คุณเพิ่มบัญชีหนึ่งครั้งในแต่ละเบราว์เซอร์ที่ใช้ จากนั้น Hivesigner จะเก็บคีย์ของบัญชีนั้นไว้ในเบราว์เซอร์ดังกล่าว โดยเข้ารหัสด้วยรหัสปลดล็อกหากคุณตั้งไว้

## เพิ่มบัญชี {#add-account}

1. ตรวจว่าแถบที่อยู่ของเบราว์เซอร์แสดง `https://hivesigner.com` ดู[ตรวจที่อยู่เว็บก่อนเสมอ](/docs/safety#check-the-address)
2. เปิด [hivesigner.com/import](https://hivesigner.com/import) ถ้าเบราว์เซอร์นี้ยังไม่มีบัญชีใดเลย ปุ่ม**ตั้งค่า Hivesigner** ที่หน้าแรกจะเปิดแบบฟอร์มเดียวกัน
3. ในช่อง**ชื่อผู้ใช้** ให้กรอกชื่อผู้ใช้ Hive ของคุณเป็นตัวพิมพ์เล็ก โดยไม่ต้องใส่ `@`
4. ในช่อง**คีย์ส่วนตัว** ให้วางคีย์ส่วนตัวของคุณคีย์ใดคีย์หนึ่ง อ่าน[ควรเพิ่มคีย์ใด](/docs/accounts#which-key)ก่อน
5. คงเครื่องหมายที่ **ป้องกันด้วยรหัสปลดล็อก (แนะนำ)** ไว้ แล้วตั้ง**รหัสปลดล็อก** ต้องยาวอย่างน้อย 4 ตัวอักษร ดู[ป้องกันด้วยรหัสปลดล็อก](/docs/accounts#passcode)
6. เลือก**เพิ่มบัญชี**

ก่อนบันทึกสิ่งใด Hivesigner จะตรวจคีย์นั้นกับบัญชีของคุณบนเครือข่าย Hive โดยเทียบเฉพาะส่วนสาธารณะของคีย์กับคีย์ที่บัญชีประกาศไว้ ตัวคีย์ส่วนตัวเองไม่ถูกส่งไปที่ใดเลย ถ้าชื่อผู้ใช้ไม่ใช่บัญชี Hive หรือคีย์ไม่ใช่ของบัญชีนั้น แบบฟอร์มจะขึ้นว่า “ชื่อผู้ใช้หรือคีย์ไม่ถูกต้อง โปรดใช้รหัสผ่านหลัก หรือคีย์ owner, active, posting หรือ memo ของคุณ”

บัญชีที่คุณเพิ่มจะกลายเป็นบัญชีที่เลือก ซึ่งเป็นบัญชีที่ Hivesigner ใช้ในหน้าจอต่าง ๆ ถ้าคุณมาที่แบบฟอร์มนี้จากคำขอใดคำขอหนึ่ง Hivesigner จะพาคุณกลับไปที่คำขอนั้น หากไม่ใช่ ก็จะเปิดหน้า**บัญชี**

### เพิ่มคีย์อีกคีย์ให้บัญชี {#add-a-key}

หากต้องการเพิ่มคีย์ที่สองให้บัญชีที่มีอยู่แล้วที่นี่ (เช่น เพิ่มคีย์ active ควบคู่กับคีย์ posting) ให้เพิ่มบัญชีนั้นอีกครั้งด้วยคีย์ใหม่ Hivesigner จะเก็บคีย์ที่มีอยู่ไว้และเพิ่มคีย์ใหม่เข้าไป คีย์ใหม่ที่เป็นชนิดเดียวกับที่มีอยู่แล้วจะแทนที่คีย์เดิม

ถ้าบัญชีมีรหัสปลดล็อก ให้คงเครื่องหมายที่ **ป้องกันด้วยรหัสปลดล็อก (แนะนำ)** ไว้และใส่รหัสเดิม กรณีอื่น Hivesigner จะปฏิเสธ

- ถ้าไม่ใส่รหัสปลดล็อก แบบฟอร์มจะขึ้นว่า “บัญชีนี้มีการป้องกันบนอุปกรณ์นี้ โปรดใส่รหัสปลดล็อกของบัญชีเพื่อเพิ่มคีย์”
- ถ้าใส่รหัสอื่น จะขึ้นว่า “รหัสปลดล็อกไม่ถูกต้อง คีย์ยังไม่ได้ถูกบันทึก”

## ควรเพิ่มคีย์ใด {#which-key}

บัญชี Hive หนึ่งบัญชีมีคีย์ส่วนตัวหลายคีย์ แต่ละคีย์ทำสิ่งต่างกัน คุณได้คีย์เหล่านี้มาจากกระเป๋าเงินหรือแอปที่สร้างบัญชี Hive ให้คุณ โดยมักอยู่ในหน้าคีย์หรือหน้ารหัสผ่านของแอปนั้น Hivesigner ไม่สามารถแสดงคีย์เหล่านั้นให้คุณดูได้

| คีย์ | Hivesigner ใช้ทำอะไร |
| --- | --- |
| Posting | เข้าสู่ระบบแอป โหวต โพสต์และแสดงความคิดเห็น ติดตาม แก้ไขโปรไฟล์ และรับรางวัล |
| Active | รายการกระเป๋าเงิน เช่น การโอน การเพิ่มหรือลด Hive Power การมอบหมาย การออม และการแปลงสกุล การโหวตพยานและข้อเสนอ การอนุญาตแอปครั้งแรกและการเพิกถอนสิทธิ์ของแอป |
| Owner | เปลี่ยนคีย์ owner หรือบัญชีสำหรับกู้คืน ในการใช้งานประจำวันไม่จำเป็นต้องใช้ |
| Memo | ไม่ได้ใช้ทำอะไร แบบฟอร์มรับคีย์นี้ แต่บัญชีที่มีเพียงคีย์ memo จะเข้าสู่ระบบไม่ได้ หน้าจอคำขอจะขึ้นว่า “เพิ่มคีย์ posting หรือ active ของ @ชื่อผู้ใช้ เพื่อดำเนินการต่อ” |

สำหรับการใช้งานประจำวันให้เพิ่มคีย์ posting เพิ่มคีย์ active เฉพาะเมื่อจำเป็นต้องใช้กับรายการกระเป๋าเงินหรือการอนุญาตแอปครั้งแรก เมื่อหน้าจอใดต้องใช้คีย์ที่อุปกรณ์นี้ไม่มี มันจะแจ้งให้ทราบและให้คุณเพิ่มคีย์ได้

ช่อง**คีย์ส่วนตัว**รับรหัสผ่านหลักด้วย Hivesigner จะสร้างคีย์ของคุณจากรหัสผ่านนั้นและเก็บทุกคีย์ที่ยังตรงกับบัญชี รวมถึงคีย์ owner การเพิ่มคีย์ทีละคีย์จะทำให้คีย์ owner ไม่เข้ามาอยู่ในอุปกรณ์นี้

> **หมายเหตุ:** Hivesigner ลงนามแต่ละธุรกรรมด้วยคีย์ที่ธุรกรรมนั้นต้องใช้เท่านั้น ซึ่งเป็นไปตามกฎของ Hive ที่มีผลตั้งแต่ฮาร์ดฟอร์กในปี 2025 คีย์ active ไม่สามารถลงนามการกระทำระดับ posting อย่างการโหวตได้อีกต่อไป และคีย์ owner ก็ลงนามรายการกระเป๋าเงินไม่ได้แล้ว ให้เพิ่มคีย์ posting แม้ว่าคีย์ active จะอยู่ที่นี่แล้วก็ตาม

การเข้าสู่ระบบแอปเป็นคนละเรื่อง เพราะไม่ใช่ธุรกรรม Hivesigner จะพาคุณเข้าสู่ระบบด้วยคีย์ posting หรือด้วยคีย์ active เมื่ออุปกรณ์นี้ไม่มีคีย์ posting ของบัญชีนั้น

## ป้องกันด้วยรหัสปลดล็อก {#passcode}

รหัสปลดล็อกคือรหัสผ่านที่คุณตั้งไว้สำหรับเบราว์เซอร์นี้เท่านั้น ไม่ใช่รหัสผ่าน Hive ของคุณ และไม่ใช่คีย์ใดคีย์หนึ่งของคุณ Hivesigner ใช้รหัสนี้เข้ารหัสคีย์ของบัญชีก่อนบันทึก และถามอีกครั้งเมื่อจะเปิดคีย์

- Hivesigner ไม่เก็บรหัสปลดล็อกของคุณและไม่ส่งไปที่ใด ไม่มีใครกู้คืนให้คุณได้
- แต่ละบัญชีบนอุปกรณ์นี้มีรหัสปลดล็อกของตัวเอง คุณจะใช้รหัสเดียวกันทั้งหมดก็ได้
- รหัสที่ยาวกว่าย่อมเดายากกว่า อย่าใช้รหัสผ่านหลักของ Hive หรือคีย์ใดคีย์หนึ่งของคุณเป็นรหัสปลดล็อก

หากไม่มีรหัสปลดล็อก Hivesigner จะเก็บคีย์ของบัญชีไว้ในเบราว์เซอร์นี้โดยไม่เข้ารหัส และจะเปิดคีย์เองทุกครั้งที่เริ่มทำงาน ใครก็ตามที่ใช้เบราว์เซอร์นี้จึงลงนามด้วยคีย์เหล่านั้นได้ หน้า**บัญชี**จะกำกับบัญชีแบบนั้นว่า**ไม่มีรหัสปลดล็อก**

หากต้องการตั้งรหัสปลดล็อกให้บัญชีที่ยังไม่มี ให้เพิ่มบัญชีนั้นอีกครั้งด้วยคีย์ของบัญชีคีย์ใดคีย์หนึ่งพร้อมรหัสปลดล็อก แล้ว Hivesigner จะเข้ารหัสคีย์ทั้งหมดของบัญชีด้วยรหัสนั้น

หากต้องการเปลี่ยนรหัสปลดล็อก ให้[ลบบัญชีออก](/docs/accounts#remove-account)แล้วเพิ่มกลับเข้ามาใหม่ด้วยรหัสใหม่ การลบจะล้างคีย์ทั้งหมดของบัญชีออกจากเบราว์เซอร์นี้ จึงต้องเพิ่มคีย์ใหม่ทีละคีย์ (คีย์ posting ก่อน แล้วค่อยคีย์ active ถ้าคุณใช้)

## ปลดล็อกบัญชี {#unlock}

บัญชีที่มีรหัสปลดล็อกจะอยู่ในสถานะล็อกทุกครั้งที่เปิด Hivesigner ไม่ว่าจะในแท็บใหม่ หลังโหลดหน้าใหม่ หรือเมื่อแอปพาคุณมาที่นี่ คุณไม่จำเป็นต้องปลดล็อกไว้ล่วงหน้า หน้าจอที่ต้องใช้คีย์จะแสดงช่อง**รหัสปลดล็อก**เหนือปุ่มของตัวเอง (เช่น **เข้าสู่ระบบ** **อนุมัติ** หรือ **ปลดล็อก**) กดครั้งเดียวก็ปลดล็อกบัญชีและดำเนินการต่อ

ถ้ารหัสไม่ถูกต้อง จะขึ้นว่า “รหัสปลดล็อกไม่ถูกต้อง” และจะไม่มีการลงนามใด ๆ

Hivesigner เก็บคีย์ที่ปลดล็อกแล้วไว้ในหน่วยความจำเท่านั้น ไม่เคยเก็บลงพื้นที่จัดเก็บ บัญชีจะยังปลดล็อกอยู่ในแท็บนั้นจนกว่าคุณจะปิดหรือโหลดหน้าใหม่

## สลับบัญชี {#switch-accounts}

หน้า**บัญชี**แสดงบัญชีบนอุปกรณ์นี้เรียงจาก A ถึง Z บัญชีที่เลือกจะมีเครื่องหมายถูก เมื่อมีบัญชีตั้งแต่ 6 บัญชีขึ้นไป ช่อง**ค้นหาบัญชี**จะช่วยกรองรายการ

เลือกบัญชีใดบัญชีหนึ่งเพื่อให้เป็นบัญชีที่เลือก ที่นี่ Hivesigner จะไม่ถามรหัสปลดล็อก ผู้ที่ถามคือหน้าจอที่ต้องใช้คีย์

ในหน้าจอคำขอ บรรทัดที่ระบุบัญชี (“เข้าสู่ระบบในนาม” “อนุญาตในนาม” หรือ “ลงนามในนาม”) จะมีลิงก์**สลับบัญชี** ลิงก์นี้เปิดรายการเดียวกันตรงนั้น ทำให้คุณเลือกบัญชีอื่นได้โดยไม่ต้องออกจากคำขอ ส่วน**เพิ่มบัญชีอื่น**ใต้รายการจะเปิดแบบฟอร์ม**เพิ่มบัญชี**แล้วพาคุณกลับมาที่คำขอ

## ลบบัญชี {#remove-account}

1. เปิดหน้า**บัญชี**
2. เลือก **✕** ข้างบัญชีนั้น ป้ายกำกับสำหรับโปรแกรมอ่านหน้าจอคือ **ลบออกจาก Hivesigner @ชื่อผู้ใช้**
3. ยืนยันเมื่อเบราว์เซอร์ถามว่า “ลบ @ชื่อผู้ใช้ ออกจากอุปกรณ์นี้หรือไม่? คีย์ของบัญชีนี้ที่เก็บไว้ที่นี่จะถูกลบ”

การลบบัญชีจะลบคีย์ออกจากเบราว์เซอร์นี้เท่านั้น บัญชี Hive ของคุณไม่เปลี่ยนแปลง แอปที่คุณอนุญาตไว้ยังคงมีสิทธิ์อยู่ เพราะสิทธิ์นั้นถูกบันทึกไว้บนบล็อกเชน Hive หากต้องการเพิกถอน ดู[ดูและเพิกถอนสิทธิ์ของแอป](/docs/signing-in#remove-access)

ถ้าคุณลบบัญชีที่เลือกอยู่ บัญชีอื่นบนอุปกรณ์นี้จะกลายเป็นบัญชีที่เลือกแทน

ถ้าเบราว์เซอร์ไม่ยอมให้ Hivesigner บันทึกการเปลี่ยนแปลง คุณจะเห็นข้อความ “ลบออกสำหรับเซสชันนี้เท่านั้น: ไม่สามารถใช้พื้นที่จัดเก็บได้ บัญชีนี้จึงจะกลับมาเมื่อคุณโหลดหน้าใหม่”

## หากคุณลืมรหัสปลดล็อก {#forgotten-passcode}

ไม่มีใครกู้รหัสปลดล็อกได้ แม้แต่ Hivesigner บัญชี Hive ของคุณไม่ได้รับผลกระทบ เพราะรหัสปลดล็อกป้องกันเพียงสำเนาคีย์ที่อยู่ในเบราว์เซอร์นี้

1. [ลบบัญชี](/docs/accounts#remove-account)ออกจากอุปกรณ์นี้
2. [เพิ่มกลับเข้ามาใหม่](/docs/accounts#add-account)ด้วยคีย์ของบัญชีและรหัสปลดล็อกใหม่

บนบล็อกเชน Hive ไม่มีอะไรเปลี่ยนแปลง แอปที่คุณอนุญาตไว้ยังคงมีสิทธิ์อยู่

## คีย์ของคุณถูกเก็บไว้ที่ไหน {#where-keys-are-stored}

Hivesigner เก็บคีย์ของคุณไว้ในเบราว์เซอร์นี้บนอุปกรณ์นี้เท่านั้น ในพื้นที่จัดเก็บที่เบราว์เซอร์กันไว้ให้ hivesigner.com

- คีย์ไม่ถูกซิงก์ เบราว์เซอร์อื่น โปรไฟล์เบราว์เซอร์อื่น หรืออุปกรณ์อื่นจะไม่มีคีย์เหล่านี้ ให้เพิ่มบัญชีที่นั่นด้วย
- การล้างข้อมูลเว็บไซต์หรือข้อมูลการท่องเว็บของ hivesigner.com จะลบคีย์ไปด้วย การปิดหน้าต่างส่วนตัวก็เช่นกัน
- Hivesigner ไม่ใช่ที่สำรองข้อมูล โปรดเก็บคีย์หรือรหัสผ่านหลักของคุณไว้อย่างปลอดภัยที่อื่น
