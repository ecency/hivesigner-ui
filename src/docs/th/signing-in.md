เมื่อแอปให้คุณเข้าสู่ระบบด้วย Hivesigner แอปจะพาคุณไปที่ hivesigner.com พร้อมกับคำขอหนึ่ง Hivesigner จะแสดงว่าใครเป็นผู้ขอ ขออะไร และบัญชีใดของคุณเป็นผู้ตอบ คุณเป็นผู้ตัดสินใจที่หน้านั้น แอปไม่เคยได้รับคีย์ของคุณ สิ่งที่แอปได้รับคือหลักฐานยืนยันชื่อผู้ใช้ของคุณที่ลงนามไว้ในเบราว์เซอร์ของคุณ

## หน้าจอคำขอ {#request-screen}

จากบนลงล่าง หน้าจอแสดง:

- **แอป** รูปภาพและหัวเรื่องของแอป เมื่อแอปขอสิทธิ์ posting เป็นครั้งแรก หัวเรื่องจะเป็น “แอป กำลังขอสิทธิ์เข้าถึงบัญชีของคุณ” กรณีอื่นจะเป็น “เข้าสู่ระบบ แอป” ชื่อในหัวเรื่องนั้นแอปเลือกเอง
- **บัญชี Hive @บัญชีแอป** บัญชี Hive จริงของแอป แอปจะตั้งชื่อเรียกตัวเองอย่างไรก็ได้ แต่เปลี่ยนชื่อนี้ไม่ได้ โปรดตรวจสอบ
- **จะพาคุณไปที่ HOST** เว็บไซต์ที่ Hivesigner จะส่งคุณกลับไปเมื่อคุณอนุมัติ
- **ขอบเขต** สิ่งที่แอปขอ: [เข้าสู่ระบบอย่างเดียวหรือสิทธิ์ posting](/docs/signing-in#scopes)
- **บรรทัดบัญชี** “อนุญาตในนาม” หรือ “เข้าสู่ระบบในนาม” พร้อมบัญชีที่แอปจะได้รับ และลิงก์**สลับบัญชี** ดู[เลือกบัญชี](/docs/signing-in#choose-account)
- **ปุ่ม** **อนุญาต** หรือ **เข้าสู่ระบบ** ถ้าบัญชีถูกล็อกอยู่ จะมีช่อง**รหัสปลดล็อก**อยู่เหนือปุ่ม กดครั้งเดียวก็ปลดล็อกบัญชีและดำเนินการต่อ
- **ยกเลิก** พาคุณไปที่หน้า**บัญชี** Hivesigner จะไม่ส่งอะไรไปให้แอป

ถ้าเบราว์เซอร์นี้ยังไม่มีบัญชีใดเลย ปุ่มจะขึ้นว่า**ดำเนินการต่อ** ปุ่มนี้จะเปิดแบบฟอร์ม**เพิ่มบัญชี**แล้วพาคุณกลับมาที่คำขอ ดู[เพิ่มบัญชี](/docs/accounts#add-account)

## เข้าสู่ระบบอย่างเดียวหรือสิทธิ์ posting {#scopes}

แอปจะขออย่างใดอย่างหนึ่งในสองอย่างนี้ ไม่มีอะไรอยู่ตรงกลาง

### เข้าสู่ระบบอย่างเดียว {#sign-in-only}

**ขอบเขต**จะแสดงว่า “ดูชื่อผู้ใช้ของบัญชีคุณ” แอปจะรู้ว่าคุณเป็นบัญชี Hive ใด โดยมีลายเซ็นของคุณเป็นหลักฐาน แต่ไม่ได้รับสิทธิ์ทำสิ่งใดแทนคุณ ปุ่มจะขึ้นว่า**เข้าสู่ระบบ**

เว็บไซต์ที่ไม่มีบัญชี Hive ของตัวเองก็ขอให้คุณเข้าสู่ระบบได้เช่นกัน หน้าจอจะขึ้นว่า “HOST ต้องการยืนยันชื่อผู้ใช้ Hive ของคุณ” คำขอแบบนี้เป็นการเข้าสู่ระบบอย่างเดียวเสมอ Hivesigner เรียกเว็บไซต์ด้วยที่อยู่ของมัน เพราะที่อยู่คือสิ่งเดียวที่คุณตรวจสอบได้

### สิทธิ์ posting {#posting-access}

**ขอบเขต**จะแสดงว่า “ด้วยสิทธิ์ posting ของคุณ แอป จะสามารถ:” ตามด้วยความหมายของสิทธิ์นั้น

- **โพสต์และแสดงความคิดเห็น:** เผยแพร่โพสต์และความคิดเห็นในนามของคุณ
- **โหวต:** โหวตขึ้นและโหวตลงด้วยบัญชีของคุณ
- **ติดตามและอัปเดตฟีดของคุณ:** ติดตาม ปิดเสียง และรีบล็อกในนามของคุณ

สิทธิ์ posting คือส่วนของบัญชี Hive ที่ดูแลการกระทำประจำวัน การอนุมัติหมายถึงการเพิ่มบัญชี Hive ของแอปเข้าไปในสิทธิ์ posting ของคุณ นี่เป็นการให้สิทธิ์ครั้งเดียวบนบล็อกเชน Hive ไม่ใช่รายการสิทธิ์ย่อยหลายรายการ

## สิทธิ์ posting ทำอะไรได้บ้าง {#what-posting-access-allows}

เมื่อมีสิทธิ์ posting แอปจะทำในนามคุณได้ทุกอย่างที่คีย์ posting ของคุณทำได้

- เผยแพร่ แก้ไข และลบโพสต์กับความคิดเห็นของคุณ
- โหวต
- ติดตาม ปิดเสียง และรีบล็อก
- แก้ไขโปรไฟล์ของคุณ
- รับรางวัลของคุณเข้ากระเป๋าเงินของคุณเอง
- การกระทำประจำวันอื่น ๆ ที่แอปและเกมบน Hive ใช้

สิ่งที่แอปทำไม่ได้เลย:

- ยักย้ายเงินของคุณ: ส่ง HIVE หรือ HBD เพิ่มหรือลด Hive Power มอบหมาย Hive Power หรือใช้เงินออมของคุณ
- เปลี่ยนคีย์ของคุณหรือเปลี่ยนผู้ควบคุมบัญชี
- ให้สิทธิ์แก่แอปอื่น

> **คำเตือน:** อนุญาตเฉพาะแอปที่คุณไว้ใจ สิทธิ์ posting จะอยู่ต่อไปจนกว่าคุณจะเพิกถอน สิทธิ์นี้ถูกบันทึกบนบล็อกเชน Hive ไม่ใช่ใน Hivesigner การลบบัญชีออกจาก Hivesigner จึงไม่ได้ยุติสิทธิ์นั้น

## ครั้งแรกที่คุณอนุญาตแอป {#first-time}

ครั้งแรกที่คุณให้สิทธิ์ posting แก่แอป หน้าจอจะแสดงข้อความนี้: “การอนุญาตครั้งแรก: การดำเนินการนี้จะเพิ่ม @บัญชีแอป ลงในสิทธิ์ posting ของคุณบนเชน และต้องใช้คีย์ active ของคุณหนึ่งครั้ง บัญชีดังกล่าวจะสามารถโพสต์ในนามของคุณได้จนกว่าคุณจะเพิกถอนสิทธิ์”

การเปลี่ยนว่าใครโพสต์แทนบัญชีคุณได้ ถือเป็นการเปลี่ยนตัวบัญชีเอง จึงต้องใช้คีย์ active ถ้าอุปกรณ์นี้ไม่มี หน้าจอจะขอทันทีตรงนั้น

1. วางคีย์ active ของคุณในช่อง**คีย์ active หรือรหัสผ่านหลักของ @ชื่อผู้ใช้** Hivesigner จะตรวจกับบัญชีของคุณบนเครือข่าย Hive แล้วบันทึกไว้บนอุปกรณ์นี้ร่วมกับคีย์อื่น ๆ ถ้าคุณวางรหัสผ่านหลัก Hivesigner จะเก็บไว้เฉพาะคีย์ active และเก็บคีย์ posting ด้วยเมื่ออุปกรณ์นี้ยังไม่มี
2. ถ้าบัญชียังไม่มีรหัสปลดล็อก แบบฟอร์มจะเสนอ**ป้องกันด้วยรหัสปลดล็อก (แนะนำ)** โดยติ๊กไว้ให้ตั้งแต่แรก ถ้าบัญชีมีอยู่แล้วและ Hivesigner ต้องใช้อีกครั้ง แบบฟอร์มจะถามในช่อง**รหัสปลดล็อกของ @ชื่อผู้ใช้**
3. เลือก**เพิ่มคีย์ active** แล้วเลือก**อนุญาต**

จากนั้น Hivesigner จะส่งการเปลี่ยนแปลงไปยังเครือข่าย Hive จากเบราว์เซอร์ของคุณ และจะรอจนการเปลี่ยนแปลงปรากฏบนบล็อกเชนก่อนจะส่งคุณกลับไปยังแอปในสถานะเข้าสู่ระบบแล้ว ถ้าใช้เวลานานเกินไป คุณจะเห็นข้อความ “ส่งการอนุญาตแล้ว แต่ยังอยู่ระหว่างการยืนยัน โปรดลองอีกครั้งในอีกสักครู่”

หลังจากนั้นคีย์ active จะยังอยู่บนอุปกรณ์นี้ หากต้องการให้เหลือเฉพาะคีย์ posting ที่นี่ ดู[เพิ่มเฉพาะคีย์ที่คุณต้องใช้](/docs/safety#only-the-keys-you-need)

## อนุญาตแอปจากไดเรกทอรี {#directory}

แอปแต่ละตัวใน [hivesigner.com/apps](https://hivesigner.com/apps) จะเปิดหน้าที่มีหัวเรื่องว่า “อนุญาต @บัญชีแอป” หน้านั้นแสดงสิ่งที่แอปเผยแพร่เกี่ยวกับตัวเอง พร้อมประโยคว่า “@บัญชีแอป จะสามารถโพสต์ แสดงความคิดเห็น โหวต และติดตามในนาม @ชื่อผู้ใช้ ได้”

การเลือก**อนุญาต**จะให้สิทธิ์ posting แก่แอปทันที เช่นเดียวกับหน้าจอการอนุญาตครั้งแรก และต้องใช้คีย์ active ของคุณ ไม่มีแอปใดร้องขอสิ่งนี้ จึงควรใช้เฉพาะเมื่อคุณตั้งใจจะทำเท่านั้น ส่วน**ยกเลิก**จะพาคุณไปที่หน้า**บัญชี**

ถ้าบัญชีของคุณให้สิทธิ์ posting แก่แอปไปแล้ว หน้านั้นจะขึ้นว่า “อนุญาต @บัญชีแอป แล้ว” พร้อมปุ่ม**ดำเนินการต่อ**

## เมื่อกลับมาที่แอปอีกครั้ง {#coming-back}

ถ้าบัญชีของคุณให้สิทธิ์ posting แก่แอปไปแล้ว จะไม่มีการให้สิทธิ์ใหม่เพิ่ม หน้าจอจะสั้นลง

- หัวเรื่องขึ้นว่า “เข้าสู่ระบบ แอป”
- มีบรรทัดหนึ่งบอกว่า “คุณเคยอนุญาต @บัญชีแอป แล้ว จะไม่มีการให้สิทธิ์ใหม่เพิ่ม”
- บรรทัดบัญชีขึ้นว่า “เข้าสู่ระบบในนาม”
- ปุ่มขึ้นว่า**เข้าสู่ระบบ**

กรณีนี้คุณต้องใช้เพียงคีย์ posting (หรือคีย์ active) ถ้าระหว่างนั้นคุณเพิกถอนสิทธิ์ของแอปไปแล้ว หน้าจอการอนุญาตครั้งแรกจะกลับมาอีก

## เลือกบัญชี {#choose-account}

บรรทัดบัญชีระบุบัญชีที่แอปจะได้รับ โปรดตรวจสอบก่อนอนุมัติ โดยเฉพาะเมื่อคุณมีหลายบัญชีบนอุปกรณ์นี้

- เลือก**สลับบัญชี**เพื่อเปิดรายการบัญชีของคุณตรงนั้น เลือกบัญชีอื่นแล้วหน้าจอจะเปลี่ยนไปใช้บัญชีนั้น
- เลือก**เพิ่มบัญชีอื่น**ใต้รายการ เพื่อเพิ่มบัญชีที่ยังไม่มีบนอุปกรณ์นี้ จากนั้น Hivesigner จะพาคุณกลับมาที่คำขอ

แอปสามารถแนะนำว่าควรใช้บัญชีใด ถ้าบัญชีนั้นอยู่บนอุปกรณ์นี้ Hivesigner จะเลือกให้ แต่คุณยังเปลี่ยนได้

## เมื่อ Hivesigner ปฏิเสธคำขอ {#refused-requests}

Hivesigner จะไม่ยอมให้คุณอนุมัติคำขอที่มันตรวจสอบไม่ได้ หน้าจอจะแสดงข้อความใดข้อความหนึ่งต่อไปนี้แทน

| ข้อความ | ความหมาย |
| --- | --- |
| “URL สำหรับเปลี่ยนเส้นทางของแอปนี้ไม่ได้ลงทะเบียนไว้ การเข้าสู่ระบบจึงถูกบล็อกเพื่อความปลอดภัยของคุณ” | ที่อยู่สำหรับส่งกลับไม่อยู่ในรายการที่แอประบุไว้บนบัญชี Hive ของตน |
| “@บัญชีแอป ไม่ใช่บัญชี Hive จึงไม่มีแอปให้อนุญาต โปรดกลับไปที่เว็บไซต์แล้วลองอีกครั้ง” | คำขออ้างถึงแอปที่ไม่มีอยู่จริง |
| “เว็บไซต์นี้ขอให้ส่งข้อมูลการเข้าสู่ระบบของคุณผ่านที่อยู่ http:// ที่ไม่ได้เข้ารหัส แต่ Hivesigner ส่งผ่าน https เท่านั้น โปรดขอให้เว็บไซต์ใช้ที่อยู่ที่ปลอดภัย” | ที่อยู่สำหรับส่งกลับไม่ปลอดภัย |
| “เว็บไซต์นี้ขอให้ส่งข้อมูลการเข้าสู่ระบบของคุณไปยังที่อยู่ที่ไม่ใช่ URL ของเว็บ โปรดกลับไปที่เว็บไซต์แล้วลองอีกครั้ง” | ที่อยู่สำหรับส่งกลับไม่ใช่ที่อยู่เว็บ |
| “คำขออนุญาตนี้ไม่สมบูรณ์: ไม่ได้ระบุแอปหรือ URL สำหรับเปลี่ยนเส้นทาง โปรดกลับไปที่แอปแล้วลองอีกครั้ง” | คำขอขาดข้อมูลบางส่วน |

โปรดกลับไปที่แอปแล้วลองอีกครั้ง ถ้าปัญหายังอยู่ ให้เลือก**รายงานปัญหานี้** ระบบจะส่งลิงก์และหมายเหตุที่คุณจะใส่หรือไม่ก็ได้ไปยังทีม Hivesigner โดยปิดบังข้อมูลลับไว้

ถ้า Hivesigner ติดต่อเครือข่าย Hive ไม่ได้ จะขึ้นว่า “ไม่สามารถโหลดรายละเอียดบัญชีจากเครือข่าย Hive ได้” ให้เลือก**ลองอีกครั้ง**

## ดูและเพิกถอนสิทธิ์ของแอป {#remove-access}

1. เปิด [hivesigner.com/authorized-apps](https://hivesigner.com/authorized-apps) ส่วนท้ายเว็บลิงก์ไปที่นั่นในชื่อ**แอปที่ได้รับอนุญาต**
2. หน้านั้นแสดงข้อความ “แอปที่สามารถโพสต์ในนาม @ชื่อผู้ใช้ ได้” สำหรับบัญชีที่เลือก พร้อมรายชื่อแอปด้านล่าง หากต้องการดูแอปของบัญชีอื่น ให้เลือกบัญชีนั้นในหน้า**บัญชี**ก่อน
3. ถ้าบัญชีถูกล็อกอยู่ ให้ใส่รหัสปลดล็อกแล้วเลือก**ปลดล็อก**
4. เลือก**เพิกถอน**ข้างแอปนั้น เมื่อคีย์ active อยู่บนอุปกรณ์นี้ สิทธิ์ของแอปจะถูกยกเลิกทันที

รายการนี้แสดงทุกบัญชีที่โพสต์ในนามคุณได้ด้วยตัวเอง รวมถึงบัญชีที่คุณเพิ่มไว้ด้วยเครื่องมืออื่น

การเพิกถอนเป็นการเปลี่ยนแปลงบัญชีของคุณบนบล็อกเชน Hive จึงต้องใช้คีย์ active หนึ่งครั้ง ถ้าอุปกรณ์นี้ไม่มี ปุ่ม**เพิกถอน**จะเปิดหน้าของแอปนั้น (“เพิกถอนสิทธิ์ของ @บัญชีแอป”) และขอคีย์ active ตรงนั้น หน้านั้นเขียนว่า “@บัญชีแอป จะไม่สามารถดำเนินการในนาม @ชื่อผู้ใช้ ได้อีกต่อไป” ให้เพิ่มคีย์แล้วเลือก**เพิกถอน**

เมื่อคุณเพิกถอนสิทธิ์ของแอป Hivesigner จะนำบัญชีของแอปออกจากสิทธิ์ posting ของบัญชีคุณ (และออกจากสิทธิ์ active ด้วย ถ้ามีอยู่ตรงนั้น) จากนั้นแอปจะโพสต์ โหวต หรือทำสิ่งใดในนามคุณไม่ได้อีก ถ้าภายหลังแอปขอสิทธิ์ posting อีกครั้ง คุณจะเห็นหน้าจอการอนุญาตครั้งแรก

การเพิกถอนไม่ได้ทำให้คุณออกจากระบบของเว็บไซต์แอปนั้น ถ้าต้องการ ให้ออกจากระบบที่นั่นด้วย
