Hivesigner est un signataire pour la blockchain Hive. Vous l’utilisez sur [hivesigner.com](https://hivesigner.com), sans rien installer. Il garde vos clés Hive dans votre propre navigateur, vous montre en mots simples ce que vous vous apprêtez à signer et permet aux applications de ne demander que l’accès dont elles ont besoin. Les applications qui l’utilisent ne reçoivent jamais vos clés.

## Par où commencer {#where-to-start}

Vous découvrez Hivesigner ? Commencez par [Ajouter et gérer des comptes](/docs/accounts). Cette page montre comment ajouter votre compte Hive, quelle clé ajouter et comment la protéger avec un code d’accès. Lisez ensuite [Gardez vos clés en sécurité](/docs/safety).

Une application vous a envoyé sur Hivesigner pour vous connecter ? [Se connecter aux applications](/docs/signing-in) explique l’écran que vous voyez, ce que l’application peut faire ensuite et comment lui retirer son accès.

Vous développez une application ? Commencez par [Comment fonctionne Hivesigner](/docs/how-it-works). Cette page explique les deux parties de Hivesigner et la façon dont votre application utilise chacune d’elles.
