সাধারণ প্রশ্নের সংক্ষিপ্ত উত্তর। প্রতিটি উত্তর বিস্তারিত পেজের সঙ্গে যুক্ত।

## Hivesigner ব্যবহার {#using-hivesigner}

### Hivesigner কি বিনামূল্যে? {#is-it-free}

হ্যাঁ। Hivesigner ব্যবহারকারী বা অ্যাপ, কারও কাছ থেকেই টাকা নেয় না। এর সোর্স কোড MIT লাইসেন্সে উন্মুক্ত।

### Hivesigner কি কখনো আমার কী দেখে? {#keys}

না। আপনার কী আপনার ডিভাইসের ব্রাউজারেই থাকে এবং Hivesigner সেখানেই সাইন করে। সেগুলো কখনোই Hivesigner-এর সার্ভারে বা আপনার ব্যবহৃত অ্যাপে পাঠানো হয় না। দেখুন [আপনার কী কোথায় রাখা হয়](/docs/accounts#where-keys-are-stored) এবং [আপনার কী নিরাপদ রাখুন](/docs/safety)।

### পাসকোড ভুলে গেলে কী হবে? {#forgotten-passcode}

পাসকোড কেউ ফিরিয়ে আনতে পারে না, Hivesigner-ও না। অ্যাকাউন্টটি Hivesigner থেকে সরিয়ে আপনার Hive কী ও নতুন পাসকোড দিয়ে আবার যোগ করুন। আপনার Hive অ্যাকাউন্ট এবং অনুমোদন দেওয়া অ্যাপগুলো বদলায় না। দেখুন [আপনি পাসকোড ভুলে গেলে](/docs/accounts#forgotten-passcode)।

### আমি কি ফোনে Hivesigner ব্যবহার করতে পারি? {#phone}

পারেন। ফোনের ব্রাউজারে https://hivesigner.com খুলে সেখানেই অ্যাকাউন্ট যোগ করুন। কী কেবল ওই ব্রাউজারেই থাকে, তাই আপনি যে ডিভাইসই ব্যবহার করুন, প্রতিটিতে অ্যাকাউন্ট যোগ করুন। দেখুন [অ্যাকাউন্ট যোগ ও পরিচালনা](/docs/accounts)।

### কোন অ্যাপগুলো Hivesigner ব্যবহার করে? {#which-apps}

https://hivesigner.com/apps-এ সেসব অ্যাপের তালিকা আছে যারা Hivesigner-এর মাধ্যমে Hive-এ লেনদেন ব্রডকাস্ট করে, সবচেয়ে বেশি ব্যবহৃতগুলো আগে। প্রতিটি অ্যাপ নিজের নাম ও বিবরণ নিজেই প্রকাশ করে, Hivesigner সেগুলো যাচাই করে না। সেখানে কোনো অ্যাপ খুললে এমন একটি পেজ আসে যেখান থেকে তাকে পোস্টিং অ্যাক্সেস দেওয়া যায়। দেখুন [ডিরেক্টরি থেকে অ্যাপ অনুমোদন](/docs/signing-in#directory)।

### Hivesigner-এর সঙ্গে Hive Keychain-এর সম্পর্ক কী? {#hive-keychain}

এগুলো আলাদা টুল। Hive Keychain একটি ব্রাউজার এক্সটেনশন ও মোবাইল অ্যাপ, আর Hivesigner একটি ওয়েবসাইট, তাই কিছু ইনস্টল করার দরকার নেই। কোনো অ্যাপ যখন বার্তায় সাইন করতে বলে, তখন তৈরি হওয়া স্বাক্ষর Hive Keychain-এর স্বাক্ষরের মতোই ধরনের, তাই অ্যাপ একই কোড দিয়ে দুটোই যাচাই করে। Hivesigner-এর **বার্তা সাইন করুন** পেজ থেকে পাওয়া যাচাইকরণ টোকেন Hivesigner-এর **বার্তা যাচাই করুন** পেজে পরীক্ষা করা হয়। দেখুন [বার্তা সাইন করা](/docs/message-signing)।

## Hivesigner দিয়ে তৈরি করা {#building}

### মোবাইল অ্যাপে কি Hivesigner ব্যবহার করা যায়? {#mobile-app}

যায়। ব্যবহারকারীকে ব্রাউজারে Hivesigner-এ পাঠান এবং এমন ফেরত ঠিকানা ব্যবহার করুন যা আপনার অ্যাপ গ্রহণ করতে পারে: আপনার নিজের মালিকানাধীন একটি https লিংক (Android App Links বা iOS Universal Links), কিংবা `http://127.0.0.1/auth`-এর মতো লুপব্যাক ঠিকানা। `myapp://`-এর মতো নিজস্ব স্কিম বাতিল করা হয়। দেখুন [মোবাইল ও ডেস্কটপ অ্যাপ](/docs/register-app#native-apps)।

### আমার কি অ্যাপ অ্যাকাউন্ট দরকার? {#app-account}

পোস্টিং অ্যাক্সেস দিয়ে মানুষকে লগইন করাতে এবং API দিয়ে ব্রডকাস্ট করতে দরকার। দেখুন [আপনার অ্যাপ নিবন্ধন করুন](/docs/register-app)। [সাইন লিংক](/docs/sign-links) আর [বার্তা সাইন করা](/docs/message-signing) এটি ছাড়াই চলে। [পোস্টিং অ্যাক্সেস ছাড়া লগইন](/docs/login-only)-ও তাই।

### API কি ট্রান্সফার পাঠাতে পারে? {#transfers}

পারে না। API কেবল পোস্টিং পর্যায়ের অপারেশন ব্রডকাস্ট করে, যেমন ভোট, মন্তব্য ও অনুসরণ। ট্রান্সফার এবং অ্যাক্টিভ কী লাগে এমন অন্যান্য কাজের জন্য [সাইন লিংক](/docs/sign-links) ব্যবহার করুন: ব্যবহারকারী নিজের কী দিয়ে প্রতিটি অনুমোদন করেন।

### কোন ভাষাগুলোর SDK আছে? {#languages}

অফিসিয়াল SDK JavaScript-এর জন্য। Python-এ কমিউনিটির লাইব্রেরি আছে। যেকোনো ভাষা থেকেই REST API ডাকা যায়। দেখুন [SDK](/docs/sdk) এবং [REST API](/docs/api)।
