Короткі відповіді на часті запитання. Кожна веде на сторінку з подробицями.

## Користування Hivesigner {#using-hivesigner}

### Hivesigner безкоштовний? {#is-it-free}

Так. Hivesigner не бере плати ні з людей, ні з застосунків. Його вихідний код відкритий за ліцензією MIT.

### Чи бачить Hivesigner мої ключі? {#keys}

Ні. Ваші ключі залишаються у вашому браузері, на вашому пристрої. Hivesigner підписує саме там. Вони ніколи не надсилаються ні на сервери Hivesigner, ні до застосунків, якими ви користуєтеся. Див. [Де зберігаються ваші ключі](/docs/accounts#where-keys-are-stored) і [Як зберегти ключі в безпеці](/docs/safety).

### Що робити, якщо я забув код доступу? {#forgotten-passcode}

Відновити код доступу не може ніхто, зокрема Hivesigner. Видаліть обліковий запис із Hivesigner і додайте його знову з ключем Hive та новим кодом доступу. Ваш обліковий запис Hive і авторизовані застосунки не змінюються. Див. [Якщо ви забули код доступу](/docs/accounts#forgotten-passcode).

### Чи можна користуватися Hivesigner на телефоні? {#phone}

Так. Відкрийте https://hivesigner.com у браузері телефона й додайте там свій обліковий запис. Ключі зберігаються лише в тому браузері, тож додавайте обліковий запис на кожному пристрої, яким користуєтеся. Див. [Додавання облікових записів і керування ними](/docs/accounts).

### Які застосунки використовують Hivesigner? {#which-apps}

На https://hivesigner.com/apps перелічено застосунки, що надсилають транзакції в Hive через Hivesigner, спочатку найпопулярніші. Кожен застосунок публікує власну назву й опис. Hivesigner їх не перевіряє. Якщо відкрити там застосунок, з’явиться сторінка, на якій йому можна надати доступ до публікацій. Див. [Авторизація застосунку з каталогу](/docs/signing-in#directory).

### Як Hivesigner пов’язаний із Hive Keychain? {#hive-keychain}

Це різні інструменти. Hive Keychain — це розширення для браузера й мобільний застосунок. Hivesigner — це сайт, тож нічого встановлювати не потрібно. Коли застосунок просить підписати повідомлення, підпис виходить такий самий, як у Hive Keychain, тож застосунок перевіряє обидва одним і тим самим кодом. Токен перевірки зі сторінки **Підписати повідомлення** в Hivesigner перевіряється на сторінці **Перевірити повідомлення** там само. Див. [Підписування повідомлень](/docs/message-signing).

## Розробка з Hivesigner {#building}

### Чи можна використовувати Hivesigner у мобільному застосунку? {#mobile-app}

Так. Надішліть користувача до Hivesigner у браузері й використайте адресу повернення, яку ваш застосунок може прийняти: посилання https на домен, яким ви володієте (Android App Links або iOS Universal Links), чи локальну адресу на кшталт `http://127.0.0.1/auth`. Власні схеми, як-от `myapp://`, відхиляються. Див. [Мобільні та настільні застосунки](/docs/register-app#native-apps).

### Чи потрібен мені обліковий запис застосунку? {#app-account}

Він потрібен, щоб виконувати вхід користувачів із доступом до публікацій і надсилати транзакції через API. Див. [Реєстрація застосунку](/docs/register-app). [Посилання для підпису](/docs/sign-links) і [підписування повідомлень](/docs/message-signing) працюють і без нього. [Вхід без доступу до публікацій](/docs/login-only) теж.

### Чи може API надсилати перекази? {#transfers}

Ні. API надсилає лише операції рівня публікації: голоси, коментарі, підписки. Для переказів та інших дій, що потребують активного ключа, використовуйте [посилання для підпису](/docs/sign-links): користувач схвалює кожне власним ключем.

### Для яких мов є SDK? {#languages}

Офіційний SDK написано для JavaScript. Для Python є бібліотеки спільноти. Звертатися до REST API можна з будь-якої мови. Див. [SDK](/docs/sdk) і [REST API](/docs/api).

## Допомога {#help}

### Де отримати допомогу? {#get-help}

Запитайте на сервері HiveDevs у Discord: https://discord.gg/pNJn7wh. Повідомляйте про помилки через issue у відповідному репозиторії GitHub: https://github.com/ecency/hivesigner-ui для сайту, https://github.com/ecency/hivesigner-api для API або https://github.com/ecency/hivesigner-sdk для JavaScript SDK. На екрані, де запит відхилено, кнопка **Повідомити про цю проблему** надсилає опис команді Hivesigner.

### Як я можу долучитися? {#contribute}

Hivesigner має відкритий код на GitHub, у трьох репозиторіях вище. Створіть issue з описом помилки або ідеї. Надішліть pull request із виправленням.
