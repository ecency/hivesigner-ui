Hivesigner 是 Hive 区块链的签名工具。您在 [hivesigner.com](https://hivesigner.com) 上使用它，无需安装任何东西。它把您的 Hive 密钥保存在您自己的浏览器里，用通俗的语言告诉您将要签名的内容，并让应用只能申请它们真正需要的权限。使用它的应用永远拿不到您的密钥。

## 从哪里开始 {#where-to-start}

第一次用 Hivesigner？请先看[添加和管理账户](/docs/accounts)。那里介绍了如何添加 Hive 账户、该添加哪个密钥，以及如何用本地密码保护它。然后阅读[保护好您的密钥](/docs/safety)。

某个应用把您送到 Hivesigner 来登录？[登录应用](/docs/signing-in)会说明您看到的界面、登录之后应用能做什么，以及如何撤销它的权限。

正在开发应用？请先看 [Hivesigner 的工作方式](/docs/how-it-works)。那里介绍了 Hivesigner 的两个组成部分，以及您的应用如何分别使用它们。
