Короткие ответы на частые вопросы. Каждый ведёт на страницу с подробностями.

## Использование Hivesigner {#using-hivesigner}

### Hivesigner бесплатный? {#is-it-free}

Да. Hivesigner не берёт плату ни с пользователей, ни с приложений. Его исходный код открыт под лицензией MIT.

### Видит ли Hivesigner мои ключи? {#keys}

Нет. Ваши ключи остаются в вашем браузере, на вашем устройстве. Hivesigner подписывает прямо там. Они никогда не отправляются ни на серверы Hivesigner, ни в приложения, которыми вы пользуетесь. См. [Где хранятся ваши ключи](/docs/accounts#where-keys-are-stored) и [Как сохранить ключи в безопасности](/docs/safety).

### Что делать, если я забыл код доступа? {#forgotten-passcode}

Восстановить код доступа не может никто, в том числе Hivesigner. Удалите аккаунт из Hivesigner и добавьте его снова с ключом Hive и новым кодом доступа. Ваш аккаунт Hive и авторизованные приложения при этом не меняются. См. [Если вы забыли код доступа](/docs/accounts#forgotten-passcode).

### Можно ли пользоваться Hivesigner на телефоне? {#phone}

Да. Откройте https://hivesigner.com в браузере телефона и добавьте там свой аккаунт. Ключи хранятся только в том браузере, поэтому добавляйте аккаунт на каждом устройстве, которым пользуетесь. См. [Добавление аккаунтов и управление ими](/docs/accounts).

### Какие приложения используют Hivesigner? {#which-apps}

На https://hivesigner.com/apps перечислены приложения, которые отправляют транзакции в Hive через Hivesigner, сначала самые популярные. Каждое приложение публикует собственные название и описание. Hivesigner их не проверяет. Если открыть приложение там, появится страница, на которой ему можно дать доступ к публикациям. См. [Авторизация приложения из каталога](/docs/signing-in#directory).

### Как Hivesigner связан с Hive Keychain? {#hive-keychain}

Это разные инструменты. Hive Keychain — это расширение для браузера и мобильное приложение. Hivesigner — это сайт, поэтому устанавливать ничего не нужно. Когда приложение просит подписать сообщение, подпись получается такой же, как у Hive Keychain, поэтому приложение проверяет обе одним и тем же кодом. Токен проверки со страницы **Подписать сообщение** в Hivesigner проверяется на странице **Проверить сообщение** там же. См. [Подпись сообщений](/docs/message-signing).

## Разработка с Hivesigner {#building}

### Можно ли использовать Hivesigner в мобильном приложении? {#mobile-app}

Да. Отправьте пользователя в Hivesigner в браузере и используйте адрес возврата, который ваше приложение может принять: ссылку https на домен, которым вы владеете (Android App Links или iOS Universal Links), либо локальный адрес вида `http://127.0.0.1/auth`. Собственные схемы, такие как `myapp://`, отклоняются. См. [Мобильные и десктопные приложения](/docs/register-app#native-apps).

### Нужен ли мне аккаунт приложения? {#app-account}

Он нужен, чтобы выполнять вход пользователей с доступом к публикациям и отправлять транзакции через API. См. [Регистрация приложения](/docs/register-app). [Ссылки для подписи](/docs/sign-links) и [подпись сообщений](/docs/message-signing) работают и без него. [Вход без доступа к публикациям](/docs/login-only) тоже.

### Может ли API отправлять переводы? {#transfers}

Нет. API отправляет только операции, которым достаточно постинг-ключа: голоса, комментарии, подписки. Для переводов и других действий, требующих активный ключ, используйте [ссылки для подписи](/docs/sign-links): пользователь одобряет каждую собственным ключом.

### Для каких языков есть SDK? {#languages}

Официальный SDK написан для JavaScript. Для Python есть библиотеки сообщества. Обращаться к REST API можно из любого языка. См. [SDK](/docs/sdk) и [REST API](/docs/api).

## Помощь {#help}

### Где получить помощь? {#get-help}

Спросите на сервере HiveDevs в Discord: https://discord.gg/pNJn7wh. Сообщайте об ошибках через issue в том репозитории GitHub, которого они касаются: https://github.com/ecency/hivesigner-ui для сайта, https://github.com/ecency/hivesigner-api для API и https://github.com/ecency/hivesigner-sdk для JavaScript SDK. На экране, где запрос отклонён, кнопка **Сообщить о проблеме** отправляет описание команде Hivesigner.

### Как я могу помочь проекту? {#contribute}

Hivesigner — проект с открытым кодом на GitHub, в трёх репозиториях выше. Создайте issue с описанием ошибки или идеи. Пришлите pull request с исправлением.
