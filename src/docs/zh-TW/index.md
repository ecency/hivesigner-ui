Hivesigner 是 Hive 區塊鏈的簽署工具。你在 [hivesigner.com](https://hivesigner.com) 上使用它，不必安裝任何東西。它把你的 Hive 金鑰保存在你自己的瀏覽器裡，用淺白的文字告訴你即將簽署的內容，並讓應用程式只能要求它們真正需要的權限。使用它的應用程式永遠拿不到你的金鑰。

## 從哪裡開始 {#where-to-start}

第一次使用 Hivesigner 嗎？請先看[新增與管理帳號](/docs/accounts)。那裡說明如何新增 Hive 帳號、該新增哪把金鑰，以及如何用本機密碼保護它。接著閱讀[保護好你的金鑰](/docs/safety)。

有應用程式把你帶到 Hivesigner 登入嗎？[登入應用程式](/docs/signing-in)說明你看到的畫面、登入之後應用程式能做什麼，以及如何撤銷它的權限。

正在開發應用程式嗎？請先看 [Hivesigner 如何運作](/docs/how-it-works)。那裡說明 Hivesigner 的兩個部分，以及你的應用程式如何分別使用它們。
