Hivesigner は Hive ブロックチェーン用の署名ツールです。[hivesigner.com](https://hivesigner.com) で使い、インストールするものはありません。Hive のキーをあなた自身のブラウザーに保管し、これから署名する内容をわかりやすい言葉で示し、アプリが必要な範囲のアクセスだけを求められるようにします。Hivesigner を使うアプリがあなたのキーを受け取ることはありません。

## どこから始めるか {#where-to-start}

Hivesigner は初めてですか。まず[アカウントの追加と管理](/docs/accounts)をご覧ください。Hive アカウントの追加方法、どのキーを追加するか、パスコードで保護する方法を説明しています。そのあと[キーを安全に保つ](/docs/safety)をお読みください。

アプリからログインのために Hivesigner に送られてきましたか。[アプリへのログイン](/docs/signing-in)では、表示される画面、ログイン後にアプリができること、アクセスを取り消す方法を説明しています。

アプリを開発中ですか。まず[Hivesigner のしくみ](/docs/how-it-works)をご覧ください。Hivesigner の 2 つの部分と、アプリがそれぞれをどう使うかを説明しています。
