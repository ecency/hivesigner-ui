アプリが Hivesigner でのログインを提供している場合、アプリはリクエストとともにあなたを hivesigner.com に送ります。Hivesigner は、誰が求めているのか、何を求めているのか、あなたのどのアカウントが応答するのかを示します。決めるのはその画面のあなたです。アプリがキーを受け取ることはありません。受け取るのは、あなたのブラウザーで署名された、ユーザー名の証明だけです。

## リクエスト画面 {#request-screen}

上から順に、画面には次が表示されます。

- **アプリ。** 画像と見出し。アプリが初めて投稿権限を求めるときの見出しは「アプリ があなたのアカウントへのアクセスを求めています。」で、それ以外は「アプリ にログイン」です。そこに出る名前はアプリが自分で決めます。
- **Hive アカウント @アプリのアカウント。** アプリの本当の Hive アカウントです。アプリは好きな名前を名乗れますが、この名前は変えられません。確認してください。
- **移動先：HOST。** 承認したときに Hivesigner が戻す先のサイトです。
- **スコープ。** アプリが求めるもの：[ログインのみか投稿権限か](/docs/signing-in#scopes)。
- **アカウントの行。**「承認に使うアカウント」または「ログインするアカウント」と、アプリが受け取るアカウント、そして**アカウントを切り替え**のリンク。[アカウントを選ぶ](/docs/signing-in#choose-account)をご覧ください。
- **ボタン。** **承認**または**ログイン**。アカウントがロックされている場合は、その上に**パスコード**欄が現れ、1 回のクリックでロックを解除して続行します。
- **キャンセル。** **アカウント**ページに移動します。Hivesigner はアプリに何も送りません。

このブラウザーにまだアカウントがない場合、ボタンは**続行**になります。**アカウントを追加**フォームを開き、そのあとリクエストに戻します。[アカウントを追加する](/docs/accounts#add-account)をご覧ください。

## ログインのみか投稿権限か {#scopes}

アプリが求めるのはこの 2 つのどちらかです。中間はありません。

### ログインのみ {#sign-in-only}

**スコープ**には「アカウントのユーザー名の参照」と表示されます。アプリはあなたがどの Hive アカウントかを、署名によって裏づけられた形で知ります。あなたに代わって行動する権限は得ません。ボタンは**ログイン**になります。

Hive アカウントを持たないサイトもログインを求められます。その画面には「HOST があなたの Hive ユーザー名の確認を求めています。」と表示されます。こうしたリクエストは必ずログインのみです。Hivesigner がサイトをアドレスで呼ぶのは、そのアドレスだけがあなたに確認できる情報だからです。

### 投稿権限 {#posting-access}

**スコープ**には「あなたの投稿権限により、アプリ は次のことができるようになります：」と表示され、その意味が続きます。

- **投稿とコメント：** あなたに代わって投稿やコメントを公開します。
- **投票：** あなたのアカウントでアップボートとダウンボートを行います。
- **フォローとフィードの更新：** あなたに代わってフォロー、ミュート、リブログを行います。

投稿権限は、日常の操作を司る Hive アカウントの一部です。承認すると、アプリの Hive アカウントがあなたの投稿権限に追加されます。これは Hive ブロックチェーン上の 1 回の付与であり、個別の権限の一覧ではありません。

## 投稿権限でできること {#what-posting-access-allows}

投稿権限があると、アプリはあなたの投稿キーでできることをすべて、あなたとして行えます。

- 投稿やコメントの公開、編集、削除
- 投票
- フォロー、ミュート、リブログ
- プロフィールの編集
- 報酬を自分のウォレットに受け取ること
- Hive のアプリやゲームが使うその他の日常的な操作

けっしてできないこと。

- 資金を動かすこと：HIVE や HBD の送金、パワーアップやパワーダウン、ハイブパワーの委任、貯蓄の利用
- キーやアカウントの支配者を変えること
- 他のアプリにアクセスを与えること

> **警告：** 信頼できるアプリだけを承認してください。投稿権限は取り消すまで続きます。Hivesigner ではなく Hive ブロックチェーンに保存されているため、Hivesigner からアカウントを削除しても終わりません。

## アプリを初めて承認するとき {#first-time}

アプリに初めて投稿権限を与えるとき、画面には次の案内が出ます。「初回の承認：@アプリのアカウント をオンチェーンであなたの投稿権限に追加するため、アクティブキーが一度だけ必要です。あなたが取り消すまで、そのアカウントはあなたとして投稿できるようになります。」

誰があなたのアカウントで投稿できるかを変えることは、アカウント自体の変更なので、アクティブキーが必要です。このデバイスにない場合、画面はその場でキーを求めます。

1. **@ユーザー名 のアクティブキーまたはマスターパスワード**にアクティブキーを貼り付けます。Hivesigner は Hive ネットワーク上のアカウントと照合し、他のキーと一緒にこのデバイスに保存します。マスターパスワードを貼り付けた場合、Hivesigner はそこからアクティブキーだけを残し、このデバイスに投稿キーがなければ投稿キーも残します。
2. アカウントにパスコードがなければ、フォームは**パスコードで保護する（推奨）**を既定でチェックした状態で示します。パスコードがあり、Hivesigner がそれを再び必要とする場合は、**@ユーザー名 のパスコード**欄で尋ねます。
3. **アクティブキーを追加**を選び、続いて**承認**を選びます。

そのあと Hivesigner は、あなたのブラウザーから変更を Hive ネットワークに送ります。変更がブロックチェーンに現れるまで待ってから、ログイン済みの状態でアプリに戻します。時間がかかりすぎると「承認は送信されましたが、まだ確認中です。少し待ってからもう一度お試しください。」と表示されます。

そのあとアクティブキーはこのデバイスに残ります。ここに投稿キーだけを残すには、[必要なキーだけを追加する](/docs/safety#only-the-keys-you-need)をご覧ください。

## ディレクトリからアプリを承認する {#directory}

[hivesigner.com/apps](https://hivesigner.com/apps) の各アプリは「@アプリのアカウント を承認」という見出しのページを開きます。そこにはアプリが自分について公開している内容と、「@アプリのアカウント は @ユーザー名 として投稿、コメント、投票、フォローができるようになります。」という文が表示されます。

**承認**を選ぶと、初回承認画面と同じように、アプリにその場で投稿権限が与えられます。アクティブキーが必要です。どのアプリからも求められていない操作なので、意図して行うときだけ使ってください。**キャンセル**は**アカウント**ページに移動します。

あなたのアカウントがすでにそのアプリに投稿権限を与えている場合、ページには「@アプリのアカウント を承認しました。」と表示され、**続行**が示されます。

## アプリに戻ってくるとき {#coming-back}

あなたのアカウントがすでにアプリに投稿権限を与えている場合、新たに付与されるものはありません。画面は短くなります。

- 見出しは「アプリ にログイン」です。
- 「@アプリのアカウント はすでに承認済みです。新たな権限は付与されません。」という行が出ます。
- アカウントの行は「ログインするアカウント」になります。
- ボタンは**ログイン**になります。

これには投稿キー（またはアクティブキー）だけで足ります。その間にアプリの権限を取り消していた場合は、初回承認の画面がもう一度出ます。

## アカウントを選ぶ {#choose-account}

アカウントの行は、アプリが受け取るアカウントを示します。承認する前に確認してください。とくにこのデバイスに複数のアカウントがある場合は注意が必要です。

- **アカウントを切り替え**を選ぶと、アカウント一覧がその場で開きます。別のアカウントを選べば、画面はそのアカウントに切り替わります。
- 一覧の下の**別のアカウントを追加**を選ぶと、このデバイスにまだないアカウントを追加できます。そのあと Hivesigner はリクエストに戻します。

アプリは使うアカウントを提案できます。そのアカウントがこのデバイスにあれば Hivesigner が選びます。それでも切り替えは可能です。

## Hivesigner がリクエストを拒否するとき {#refused-requests}

Hivesigner は、確認できないリクエストを承認させません。代わりに次のいずれかが表示されます。

| メッセージ | 意味 |
| --- | --- |
| 「このアプリのリダイレクト URL は登録されていません。安全のため、サインインはブロックされました。」 | 戻り先のアドレスが、アプリが自分の Hive アカウントに登録したものに含まれていません。 |
| 「@アプリのアカウント は Hive アカウントではないため、承認できるアプリがありません。サイトに戻ってもう一度お試しください。」 | リクエストが存在しないアプリを指しています。 |
| 「このサイトは、暗号化されていない http:// のアドレスにログイン情報を送るよう求めています。Hivesigner は https でのみ送信します。安全なアドレスを使うようサイトに依頼してください。」 | 戻り先のアドレスが安全ではありません。 |
| 「このサイトは、Web の URL ではないアドレスにログイン情報を送るよう求めています。サイトに戻ってもう一度お試しください。」 | 戻り先のアドレスが Web アドレスではありません。 |
| 「この承認リクエストは不完全です（アプリ名またはリダイレクト URL が指定されていません）。アプリに戻ってもう一度お試しください。」 | リクエストに欠けている部分があります。 |

アプリに戻ってもう一度お試しください。それでも解決しない場合は**この問題を報告**を選んでください。リンクと任意のメモが、秘密の情報を伏せたうえで Hivesigner チームに送られます。

Hivesigner が Hive ネットワークに接続できない場合は「Hive ネットワークからアカウント情報を読み込めませんでした。」と表示されます。**再試行**を選んでください。

## アプリのアクセス権を見て取り消す {#remove-access}

1. [hivesigner.com/authorized-apps](https://hivesigner.com/authorized-apps) を開きます。フッターからは**承認済みアプリ**としてリンクしています。
2. 選択中のアカウントについて「@ユーザー名 として投稿できるアプリです。」と表示され、その下に各アプリが並びます。別のアカウントのアプリを見るには、先に**アカウント**ページでそのアカウントを選んでください。
3. アカウントがロックされている場合は、パスコードを入力して**ロック解除**を選びます。
4. アプリの横の**取り消す**を選びます。アクティブキーがこのデバイスにあれば、アプリのアクセス権はその場でなくなります。

一覧には、あなたのアカウントとして単独で投稿できるアカウントがすべて表示されます。他のツールで追加したものも含まれます。

権限の取り消しは Hive ブロックチェーン上のアカウントの変更なので、アクティブキーが一度必要です。このデバイスにない場合、**取り消す**はそのアプリ用のページ（「@アプリのアカウント の権限を取り消す」）を開き、そこでアクティブキーを求めます。そこには「@アプリのアカウント は @ユーザー名 として操作できなくなります。」と表示されます。キーを追加してから**取り消す**を選んでください。

アプリの権限を取り消すと、Hivesigner はそのアプリのアカウントをあなたのアカウントの投稿権限から外します（アクティブ権限にもあれば、そちらからも外します）。それ以降、アプリはあなたとして投稿も投票も操作もできません。あとでアプリが再び投稿権限を求めた場合は、初回承認の画面が表示されます。

権限を取り消しても、アプリ自身の Web サイトからはログアウトされません。必要ならそちらでもログアウトしてください。
